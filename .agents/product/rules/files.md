## A member reads, searches and changes the files of its own computer

Without file tools a member would read, search and change the files of its own computer through `vm_exec` (`cat`, `sed`, heredocs): the head of the output only, no line numbers, no paging, no check that the text it replaced was the text it had read, and whole files under the 16,000-character argument cap. These rows give it five file tools on its own computer: `read_file`, `edit_file`, `write_file`, `glob` and `grep`. They are computer tools (server `computer`, listed whole, T0 in the sandbox), so they exist exactly when the member has a computer and reach every brain, CLI brains through the computer MCP server; the CLI vendors' own file and shell tools stay off (they would act on the owner's PC outside Raphael's card, R-PC-02). No approval card is added for a member's own files.
